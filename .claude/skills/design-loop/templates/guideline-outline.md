# Guideline 章節骨架（Ant Design 形式）

parts 檔名前綴＝組裝順序，`00_head.html`、`99_foot.html` 固定頭尾。章節編號可以和檔名順序不同（例：盤點放前面但編 02）。

| 章 | 標題 | 一定要有 |
|---|---|---|
| 00 | 使用方式 | 規範優先順序、三種讀者（設計／工程／AI）怎麼用、不可違反的硬規則、名詞 |
| 01 | 設計原則 | 3–5 條，每條附「所以會這樣做／不會這樣做」 |
| 02 | 現況盤點與統一決策 | audit.md 摘要：主要不一致與決策、已經一致直接沿用 |
| 03 | 色彩 | 色板（ref）、語意角色（sys）、文字層級示範、底色規則、強調色、影像疊色與玻璃、對比度 |
| 04 | 字體與字級 | 字體分工、字級階層 H1–H6 與文字角色（各 viewport，標示標題或閱讀型）、字樣、規則（含 Figma 換算註記）、RWD 字級標準（標題手機 ≤ 桌機；閱讀型手機 ≥14px，內文建議 16px，見 s1） |
| 05 | 版面、網格與 RWD | 斷點或裝置、容器與欄網格、分割樣板、區塊節奏、重排規則 |
| 06 | 間距 | 間距階梯、常用組合 |
| 07 | 形狀、層級與玻璃 | 圓角、陰影層級、模糊、線條 |
| 08 | 影像與圖示 | 影像分類、比例與尺寸、圖說與替代文字、圖示規格與清單 |
| 09 | 動態 | 時長與曲線 token、動態樣式、減少動態 |
| 10 | 元件 | 每個元件：用途、何時用／不用、結構、變體與狀態、規格表（token）、Do／Don't、class 與 HTML 範例 |
| 11 | 頁面樣板 | 樣板總覽、各樣板區塊順序、Wireframe 標註 → 元件對照、遇到新區塊的判斷步驟、（CMS 專案）欄位對照表 |
| 12 | 無障礙 | 對比、觸控／點擊區、焦點、語意標記 |
| 13 | 文案與資料 | 日期與數字格式、文案規則 |
| 14 | AI 延展流程 | 步驟、指令範本、自我檢查清單、回報格式（對應 design-loop S6／S7） |
| 15 | 對標 | 採用與取捨總表（Web：Ant Design × Material 3；APP：Material 3 × Apple HIG）、官方來源 |
| 16 | 檔案與 Token | 檔案清單、新頁面怎麼引用、與網站的關係、維護與版本紀錄、Figma 設計檔慣例（page、命名、換算） |

APP 另補的章節見 `platforms/app.md`。
