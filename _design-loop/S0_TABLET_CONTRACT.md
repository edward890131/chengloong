# S0 平板（768）契約：逐段混合

沿用 `S0_CONTRACT.md` 的所有規則（檔案所有權、命名、不准改 base、回報格式），本檔只寫差異；衝突時以本檔為準。

## 決策（使用者 2026-10-20 選「逐段混合」）

設計稿沒有平板版。平板範圍＝**641–1100px**（manifest `modes.Responsive` Tablet＝`@media (max-width:1100px)`），驗收寬 **768×1024**，另看 1024 不破版。每段用下表的結構：

| 段落 | 平板結構 | 重點 |
|---|---|---|
| 01 首屏 | 電腦結構 | header 改手機樣式（logo＋預約＋漢堡，隱藏中間導覽與企業登入）；cover 右上、白卡左下、數據區右下，依比例縮；數據區 2×2 不擠字 |
| 02 什麼是水銷 | 電腦結構 | 四卡 2×2；循環圖用電腦版 SVG 等比縮 |
| 03 從文件到用紙 | 電腦結構 | 2 欄圖文交錯；Step 03 說明卡改直排 |
| 04 服務流程 | 混合 | 四格卡改**手機結構**（上下排，每格高 200，展開互動不變）；頁籤 1 線上預約用**手機結構**（步驟在上、圖在下）；頁籤 2 用電腦 2 欄；頁籤 3 用**手機結構**（可左右滑動＋提示） |
| 05 綠點存摺 | 混合 | 卡片內改成：文字區滿寬在上，下方「圖卡｜右側兩格」2 欄；兩張卡維持上下排（不橫滑） |
| 06 串場 | 電腦結構 | 照片尺寸介於兩版之間（照片框 280×168、間距 28），平移距離跟著換算 |
| 07 FAQ | 電腦結構 | 左右留白 40；頁籤一列放得下就不換行 |
| 08 CTA | 電腦結構 | 左右留白 40；按鈕維持 18px 並排 |
| 09 頁尾 | 電腦結構 | 資訊欄可換行；標語字級依寬縮放、不出水平捲軸 |

- 全段左右版心留白 40px（標題區照原本置中）。
- 字級：標題介於兩版之間（區段標題 28、卡片標題照電腦版），內文照電腦版。
- 641–1100 原本的流動縮放規則改寫成上表；**1101–1439 與 ≤640 的現有樣式不准改壞**。

## 驗收

1. 768×1024、1024×768 各截整段（`isMobile: true, hasTouch: true`；`?static`），存 `_design-loop/evidence/s0-tablet/NN-<slug>/`。
2. 無水平捲軸、無重疊、無裁字、無擠成一字一行；互動在 768 可用（點擊、橫滑）。
3. **回歸**：1440 與 375 再跑一次段落截圖，和 S0 驗收時的 `_design-loop/evidence/s0/NN-<slug>/` 比，不得變差（位置差、像素差維持）。
4. 回報寫進回覆訊息（REPORT 檔寫不進去就不用試）：每段做法、768／1024 截圖路徑、回歸結果、給主控的需求。
